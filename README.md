## Overview of the language and the .NET platform

C# is a language that was officially released in February 2002, alongside Microsoft’s .NET 1.0 platform, to which it is intrinsically linked. C# requires this runtime environment to function, which provides a very extensive set of classes.

At first glance, the .NET platform is a runtime environment similar to a Java virtual machine, with a few notable differences:

**Cross-platform**: Whilst Java has run on various operating systems since its inception, .NET was initially restricted to Windows. However, the **[Mono](http://www.mono-project.com)** project now allows .NET to be used on systems such as Unix and Linux.


**Multi-language**: The .NET platform allows programmes written in different languages to run, provided their compiler produces IL (Intermediate Language) code. All .NET classes are available for these languages, which tends to blur the differences between them; choosing a .NET language then becomes a matter of preference rather than performance.





## Evolution of the language

In 2002 (C# 1.0), the language was very similar to Java, making the transition from one environment to the other easier. Since then, the specific characteristics of each language have become more distinct.

With the arrival of C# 3.0 and the .NET 3.5 framework, numerous new features emerged, the most significant of which is probably **LINQ** (Language INtegrated Query). LINQ allows you to query arrays, lists, databases or XML files in a uniform manner (similar to SQL).
